# AI Reel Studio (Windows)

A native Windows 10/11 (x64) desktop application built with **Tauri 2**, **React**, **TypeScript**, and **Rust**.

This repository is at **Phase 0: desktop foundation**. It delivers a real, packageable native
desktop application shell with a verified frontend-to-Rust IPC path, quality gates, and Windows
installers (NSIS + MSI). Product features are intentionally out of scope at this phase.

## Prerequisites

| Requirement                             | Notes                                                             |
| --------------------------------------- | ----------------------------------------------------------------- |
| Windows 10/11 x64                       | Build and target platform                                         |
| Node.js >= 22                           | Includes npm (npm >= 11 recommended)                              |
| Rust (stable, `x86_64-pc-windows-msvc`) | Install via [rustup](https://rustup.rs)                           |
| Visual Studio 2022 Build Tools          | "Desktop development with C++" workload (MSVC v143 + Windows SDK) |
| WebView2 Runtime                        | Preinstalled on Windows 11; Evergreen on updated Windows 10       |

## Setup

```powershell
npm install
```

## Commands

### Frontend and packaging

| Command                | Description                                                               |
| ---------------------- | ------------------------------------------------------------------------- |
| `npm run dev`          | Start the Vite dev server (frontend only, port 1420)                      |
| `npm run tauri dev`    | Run the native desktop app in dev mode with hot reload                    |
| `npm run tauri build`  | Type-check, bundle, compile Rust (release), produce NSIS + MSI installers |
| `npm run test`         | Run frontend unit tests (Vitest)                                          |
| `npm run test:watch`   | Run tests in watch mode                                                   |
| `npm run typecheck`    | TypeScript check, no emit                                                 |
| `npm run lint`         | ESLint                                                                    |
| `npm run format`       | Prettier write                                                            |
| `npm run format:check` | Prettier check                                                            |
| `npm run icon`         | Regenerate `assets/app-icon.png` and the full Tauri icon set              |

### Rust (run inside `src-tauri/`)

| Command                       | Description                  |
| ----------------------------- | ---------------------------- |
| `cargo fmt --check`           | Verify formatting            |
| `cargo clippy -- -D warnings` | Lint with warnings as errors |
| `cargo test`                  | Run Rust unit tests          |

## Project structure

```
├─ index.html                 Vite entry point
├─ src/                       React + TypeScript frontend
│  ├─ App.tsx                 Foundation verification root component
│  ├─ lib/appInfo.ts          Typed IPC wrapper (invoke -> Rust)
│  └─ test/setup.ts           Vitest setup (jest-dom matchers)
├─ src-tauri/                 Rust native application
│  ├─ src/main.rs             Windows entry point
│  ├─ src/lib.rs              Tauri builder, IPC commands, unit tests
│  ├─ tauri.conf.json         Window, bundling, and security configuration
│  ├─ capabilities/           Tauri 2 permission capabilities
│  └─ icons/                  Generated icon set (from assets/app-icon.png)
├─ assets/app-icon.png        Icon source (generated by scripts/make-icon.mjs)
└─ scripts/                   Node tooling scripts
```

## Architecture notes

- The web view is a thin UI layer; native capabilities, filesystem access, and any privileged
  work belong on the Rust side, exposed through typed `invoke` commands.
- The `main` window runs under the `default` capability (`core:default` permissions only).
  New capabilities must be added explicitly as native features grow.
- Content Security Policy is set in `src-tauri/tauri.conf.json`; relaxations must be justified
  per feature.
- Installers are produced to `src-tauri/target/release/bundle/` (`nsis/` and `msi/`).

## Phase 0 exit criteria

- `npm run tauri build` succeeds and produces installers.
- Frontend gates green: `typecheck`, `lint`, `format:check`, `test`.
- Rust gates green: `fmt --check`, `clippy -- -D warnings`, `test`.

Code signing and CI are planned for a later phase.
